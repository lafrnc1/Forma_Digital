# Forma Digital

Site vitrine statique en HTML, CSS et JavaScript.

## Lancer le site

Ouvrez `index.html` directement dans un navigateur, ou utilisez un serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez `http://localhost:8000`.

## Modifier le contenu

- Textes, sections et liens : `index.html`
- Couleurs, polices, espacements et responsive : `styles.css`
- Menu mobile, animations et validation du formulaire : `script.js`
- Favicon provisoire : `favicon.svg`

## Configuration avant mise en ligne

1. Remplacez le lien WhatsApp provisoire dans `index.html`.
2. Ajoutez une adresse email réelle si nécessaire.
3. Connectez le formulaire à Formspree, un autre service compatible, ou une API backend.
4. Remplacez les images Unsplash de démonstration si vous utilisez les projets dans un portfolio commercial.
